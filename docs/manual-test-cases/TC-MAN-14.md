# TC-MAN-14
**Title:** Register a new customer account
**Type:** Positive / Regression
**Priority:** High

## Precondition
nopCommerce is running at http://localhost:8081/
User is not logged in.
A new email address is available for testing.

## Test Steps
1. Open the homepage.
2. Click Register.
3. Enter valid first and last name.
4. Enter a new email address.
5. Enter a valid password.
6. Confirm the password.
7. Click Register.
8. Verify the registration result.

## Expected Result
Registration is completed successfully.
A registration confirmation message is displayed.
No validation errors are displayed.

**Actual Result:** 
A new customer account was successfully registered using valid test data.
Registration confirmation was displayed without validation errors.
